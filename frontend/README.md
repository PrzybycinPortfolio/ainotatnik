# AI Notatnik — frontend

React 19 + TypeScript + Vite app (Czat · Notatki · Faktury), deployed to Cloudflare Pages.

See the [main README](../README.md) for features, architecture and setup.

```bash
npm install
npm run dev     # http://localhost:5173 (needs .env — see .env.example)
npm run build   # type-check + production build to dist/
```
